          Calendars

          Events, birthdays and holidays appear under the clock and in its detail view. Each day shows an item only once, even if several calendars contain it. Calendar addresses are private and are set on the Pi in .env (AURA_CALENDAR_FEEDS); they are never shown here.

          Assistant

          Privacy: the microphone only turns on when someone presses the microphone button (or the remote's shortcut) on the entrance screen, or on a phone or laptop if you allow that above, and every open screen shows Listening while it is on. Speech is recognised on the Pi itself; audio is never saved or sent anywhere. Questions and answers are kept in memory until cleared or AURA restarts. The assistant can only answer questions; it can't change data or settings.

          Network protection

            Pi-hole blocks ad and tracker domains for devices that use this Pi for DNS. It can't remove ads served from the same domain as the content (most YouTube and many in-app ads), and devices using encrypted or fixed DNS bypass it. Manage blocklists, the query log and allowed domains in Pi-hole's own admin page: open Pi-hole admin (it asks for its own password).

            Wi-Fi

              Connect to

              Other ways to change Wi-Fi
              • On the Pi's screen: exit the dashboard with Alt+F4 (or connect a keyboard), then use the network icon in the top-right of the Raspberry Pi desktop.
              • Over SSH (Ethernet): nmcli device wifi list, then nmcli --ask device wifi connect "Network name" (it asks for the password).
              • Text menu: run sudo nmtui → Activate a connection.
              • If you lose access: plug in an Ethernet cable (the Pi keeps that connection) or use a keyboard and screen; saved networks reconnect automatically.
